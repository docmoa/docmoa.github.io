### Start contributing to `docmoa`

::: important Run info
Minimum tested NodeJS version : `v20.19.x`
:::

::: code-tabs
@tab npm

```bash {2,5-6,9}
# git clone
git clone https://github.com/docmoa/docs.git
# npm install
cd docs
npm install
# start VuePress writing
npm run dev
```

@tab yarn

```bash {2,5-6,9}
# git clone
git clone https://github.com/docmoa/docs.git
# npm install
cd docs
yarn install
# start VuePress writing
yarn vuepress dev
```

:::
